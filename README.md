# سیستم مدیریت سازمانی (Tailux Admin)

## 📋 معرفی کلی
این پروژه یک پنل مدیریت مدرن و حرفه‌ای است که با استفاده از جدیدترین تکنولوژی‌های روز دنیا ساخته شده است. این سیستم برای مدیریت شرکت‌ها، کارکنان، محصولات، فاکتورها و سایر امور سازمانی طراحی شده است.

---

## 🛠️ تکنولوژی‌های استفاده‌شده

| بخش | تکنولوژی |
|-----|----------|
| **فریم‌ورک اصلی** | React 19 |
| **زبان برنامه‌نویسی** | TypeScript |
| **بیلد تول** | Vite 7 |
| **استایل‌دهی** | TailwindCSS 4 |
| **مسیریابی** | React Router 7 |
| **مدیریت فرم** | React Hook Form + Yup |
| **جدول داده‌ها** | TanStack Table |
| **نمودارها** | ApexCharts |
| **چندزبانه** | i18next (فارسی، انگلیسی، عربی) |
| **HTTP Client** | Axios |
| **احراز هویت** | JWT Token |

---

## 📁 ساختار بخش‌های سیستم

### 1️⃣ داشبوردها (Dashboards)
بخش اصلی سیستم که شامل صفحات زیر است:

#### 🏠 خانه (Home)
- صفحه اصلی داشبورد
- نمایش خلاصه وضعیت سیستم

#### 🏢 شرکت‌ها (Companies)
- مدیریت اطلاعات شرکت‌ها
- ثبت، ویرایش و حذف شرکت‌ها
- جستجو و فیلتر کردن شرکت‌ها

#### 📦 واحدها (Units)
- مدیریت واحدهای سازمانی
- تعریف واحدهای مختلف برای شرکت‌ها

#### 📋 آیتم‌ها (Items)
- مدیریت آیتم‌ها و محصولات
- دسته‌بندی و سازماندهی آیتم‌ها

#### 👥 کارکنان (Employees)
- مدیریت اطلاعات پرسنل
- ثبت و پیگیری اطلاعات کارکنان

#### 📅 دوره‌ها (Periods)
- مدیریت دوره‌های مالی و کاری
- تعریف بازه‌های زمانی مختلف

#### 📥 ایمپورت‌ها (Imports)
- وارد کردن داده‌ها از فایل‌های خارجی
- پشتیبانی از فرمت‌های مختلف

#### 📄 فاکتورها (Invoices)
- مدیریت فاکتورهای فروش و خرید
- صدور و پیگیری فاکتورها

---

### 2️⃣ ابزارها (Tools)

#### 🧾 فیش حقوقی (Salary Receipt)
- تولید و مدیریت فیش‌های حقوقی
- محاسبه حقوق و دستمزد کارکنان

---

### 3️⃣ تنظیمات (Settings)

#### ⚙️ تنظیمات عمومی (General)
- پیکربندی کلی سیستم
- تنظیمات پایه و اولیه

#### 🎨 ظاهر (Appearance)
- شخصی‌سازی تم و رنگ‌بندی
- تنظیمات نمایشی سیستم

---

### 4️⃣ احراز هویت (Authentication)
- صفحه ورود به سیستم
- مدیریت توکن‌های امنیتی
- محافظت از صفحات با AuthGuard

---

### 5️⃣ صفحات خطا (Error Pages)
- ❌ 401 - عدم دسترسی
- ❌ 404 - صفحه یافت نشد
- ❌ 429 - درخواست بیش از حد
- ❌ 500 - خطای سرور

---

## 🌐 چندزبانه (i18n)
سیستم از ۳ زبان پشتیبانی می‌کند:
- 🇮🇷 فارسی (Fa)
- 🇬🇧 انگلیسی (En)
- 🇸🇦 عربی (Ar)

---

## 🔧 ویژگی‌های کلیدی

✅ **ریسپانسیو** - سازگار با تمام دستگاه‌ها (موبایل، تبلت، دسکتاپ)  
✅ **تم تاریک/روشن** - قابلیت تغییر تم  
✅ **منوی کناری** - ناوبری آسان بین بخش‌ها  
✅ **جستجوی پیشرفته** - فیلتر و جستجو در داده‌ها  
✅ **آپلود فایل** - پشتیبانی از آپلود فایل با FilePond  
✅ **ویرایشگر متن** - ویرایشگر غنی Quill  
✅ **تقویم شمسی** - پشتیبانی از تاریخ jalali  
✅ **صادرات PDF** - امکان خروجی PDF از گزارشات  
✅ **Notifications** - نمایش اعلان‌ها با Sonner

## 🚀 نحوه اجرا

### پیش‌نیازها
- Node.js (نسخه 18 یا بالاتر)
- npm یا yarn

### نصب و راه‌اندازی

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت نسخه تولید
npm run build

# بررسی کدها
npm run lint
```

## 📂 ساختار پوشه‌ها

```
src/
├── app/
│   ├── contexts/        # مدیریت stateهای سراسری (تم، زبان، سایدبار، احراز هویت)
│   ├── layouts/         # قالب‌بندی صفحات
│   ├── navigation/      # تنظیمات منو و ناوبری
│   ├── pages/           # صفحات اصلی برنامه
│   ├── router/          # تنظیمات مسیرها
│   └── services/        # سرویس‌های ارتباط با API
├── components/
│   ├── shared/          # کامپوننت‌های مشترک
│   ├── template/        # کامپوننت‌های قالب
│   └── ui/              # کامپوننت‌های UI
├── hooks/               # هوک‌های سفارشی React
├── i18n/                # تنظیمات چندزبانه
├── utils/               # توابع کمکی
└── styles/              # استایل‌های سراسری
```
